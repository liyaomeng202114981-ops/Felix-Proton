# Felix Proton UU Test 0.1.0-test.1

这是 Felix Li 基于 SHORiN-KiWATA 的 WE-Proton 制作的本机试用版，面向 Linux 原生 Steam 和网易 UU 的路由模式。加速目标由 UU 的游戏、区服、模式和节点决定。Steam 在同一独立网络中启动后，通常由它启动的游戏继承这个网络，仍可使用游戏自己原有的 Proton 版本和启动参数。

## 开始一轮测试

1. 正常退出原先运行的 Steam 和 UU。在应用列表搜索 **网易 UU（Felix 测试版）**。首次使用的独立前缀需要完成官方 UU 安装并登录。测试版会识别机器上已下载的官方安装包。
2. 在 UU 中选择第一款游戏、区服和支持路由模式的节点，开始加速。用 **Steam（Felix UU 测试版）** 打开 Steam，从库中启动游戏。不需要为普通 Steam 游戏逐个写启动命令。
3. 想换游戏时，先退出第一款游戏，在 UU 停止加速，然后选第二款的游戏、区服和节点，重新加速。Steam 可以留在同一网络里。启动器若提示 Steam 已在其他网络，请从 Steam 菜单正常退出，再用测试版入口打开。
4. 卡住时可以短暂保留现场。直接在聊天里说“刚才卡了”就可以排查，无需记时间或复制日志。在同时做多次尝试时，可以用桌面入口的右键动作标记一次异常。

## 自动记录

由两个测试入口启动时，记录器在外部程序启动前打开时间线。安装、启动请求、拒绝和退出状态与下列观测共用本地时间戳。UU 运行时采样现有网络会话，大约每秒检查一次，状态不变时每 15 秒留一次心跳。特定调用只是线索，UU 是否连上远端节点仍取决于客户端和实际业务连接。

- 核实网络会话后，记录 UU 网卡的出现和消失、主 IPv4 路由表中经过它的条数、网卡累计收发字节，以及原生 Steam 的网络归属。
- 从启动器和 Wine 输出提取 Wintun 创建、开始、结束、关闭等调用及可辨认的网络错误。流量走向还需对照网卡计数与路由。
- 追踪 UU 的三份网络日志是否创建、增长、截断或轮换，只将可识别的信号写入时间线。本机已见版本使用十六进制记录。遇到这种格式只能看到日志活动，所选节点、窗口提示和点击时刻有时无法读取。
- Steam 在测试网络里运行时，从它新增的游戏进程记录提取 AppID、进程增减和可用的退出码。它表示 Steam 实际启动的应用；UU 当前选中的加速目标需要单独核对。
- 时间线只存本地，使用固定字段，不保存账号、验证码、聊天、完整命令行、数据包内容或访问地址，也不上传。现有 Steam、UU 和上游 wrapper 各自的正常日志仍由它们自行管理。本机诊断保留最近 8 轮，一轮最多三个约 2 MiB 文件。启动动作持续或网络会话存在时继续记录，二者均结束且空闲约 90 秒后结束该轮。

记录目录是 `~/.local/state/felix-proton-uu/0.1.0-test.1/` 下对应此测试前缀的子目录（设置 XDG_STATE_HOME 时跟随该设置）。每轮的 `events.jsonl` 一行一个事件，`latest` 指向最近一轮。只读定位命令如下。

```sh
runner="$HOME/.local/share/Steam/compatibilitytools.d/felix-proton-uu-test-0.1.0-test.1"
python3 "$runner/felix/observe.py" latest --prefix "$HOME/Games/Felix-UU-0.1.0-test.1"
python3 "$runner/felix/local-beta.py" check --json
```

## 归属与版本

| 工作 | 来源 |
| --- | --- |

| Wine 内置 Wintun 对接 Linux TUN、网卡地址与新旧路由接口、让 UU 识别网卡的补丁 | SHORiN-KiWATA 的 [WE-Proton](https://github.com/SHORiN-KiWATA/we-proton)。原作者记录了 AI 辅助开发和测试。 |
| 按前缀创建/加入独立网络、让原生 Steam 加入的机制 | SHORiN-KiWATA 的 [proton-wrapper](https://github.com/SHORiN-KiWATA/proton-wrapper)。对外联网依赖 [passt/pasta](https://passt.top/passt/about/)。UU 决定目标业务如何加速。 |
| 修复网卡删除或改名后仍返回旧的名称与索引（0062），在一次路由枚举中复用有效接口转换，消除 0062 引入的重复查询开销（0063），提供受保护的启动入口 | Felix Li 在 OpenAI Codex 协助下开发、测试和整理。[上游提案与对照实验](https://github.com/SHORiN-KiWATA/we-proton/pull/1)。 |
| 本机测试版的独立版本标识、双入口、自动时间线、启动器兼容修复及测试 | Felix Li 与 OpenAI Codex。保留 Steam 入口的符号链接语义，按原始字节识别进程名，避免非 UTF-8 名称中断启动。 |

本包复用 WE-Proton `we-proton-ge11-11-31` 上历史实测的 `desktop-netfix2` 二进制。这里还含本地桌面补丁 0061 及配套 Python 代码。网络补丁对应 PR 的 0062、0063。版本、模块哈希和历史提交在根目录的 felix-build.json。本轮为该运行器换用独立发行标识并配上新的启动及诊断代码。源码包和构建说明见发行目录。版权、许可与原作者信息见包内 LICENSE* 和上游文档。

完整运行器已在隔离的 Steam Runtime SDK 中启动 64 位与 32 位 WoW64 探针。测试网络也已观察到合成网卡和路由的建立与撤销。本机真实 UU 的节点切换、建立耗时及第二款游戏的实际连接，需要用本次试用结果来判断。单靠路由已经出现或 Steam AppID 已启动，不能证明真实加速成功或延迟有所改善。

## 回到原来的版本

正常退出测试版 UU 和 Steam，使用之前的稳定版入口即可。测试版使用单独的前缀和 Steam 工具目录。若希望移走测试版快捷方式，在测试版退出后运行 `python3 "$runner/felix/local-beta.py" uninstall`。个人数据和诊断记录保留，方便回看和复测。
