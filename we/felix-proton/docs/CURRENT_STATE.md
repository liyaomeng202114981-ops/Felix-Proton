# 当前公开状态

更新于 2026-11-06（Asia/Shanghai）。本页记录本机结果，异机与全面兼容性仍待验证。

Felix-Proton 在独立仓库的 `main` 分支维护，保留 WE-Proton 的来源、许可和提交历史。现有源码包含 CM 目录代理、就绪通知和性能优化。[从零配置完整流程说明](FROM_ZERO.md)

发行版构建、固定运行器分发和 GitHub Release 继续暂缓。

- 普通 Steam 与 UU 图标已接入共享前缀网络，通常无需逐款游戏配置参数；用户在 UU 中选择目标和路由模式。
- 0062 修复失效接口映射，0063 消除同次枚举重复查询的性能回退；已有公开报告与合成测试。
- 新增 Python CM 控制连接保护。部署验证确认精确 TCP 目标走保护出口，其他端口与 UDP 保持原路径，宿主机路由与规则未变。
- 用户已明确确认本轮切换加速时原有 Steam 掉线问题解决；没有与此次用户复测同步的整夜逐次断线时长测量。
- CM 目录查询可读取 GNOME 手动配置的本机回环代理。守护首次就绪时提示一次，初次超时后恢复也会提示。
- CM 性能更新继续使用 Python。准备阶段响应查询完成事件，批量写入精确规则并逐条核验路由，减少重复状态写入。
- 性能更新时 69 项隔离集成测试通过。三轮真实目录与 DNS 的隔离测试，就绪中位时间为 0.896 秒。实际会话日志另记录最多 19 条规则并在退出时清理。[性能与验收范围](TESTING.md#cm-性能复测)
- 已修复 CM 正常退出时的 `FileNotFoundError` 误报。守护在维护期间读不到 keeper 身份文件时，进入已有规则回收流程。两种退出顺序的前后对照及 70 项集成测试通过。[退出状态复测](TESTING.md#cm-退出状态复测)
- 用户此前确认 CM 目录代理和就绪通知更新通过本机实测。66 项、64 项集成测试和 16 项采集器测试均为历史结果。
- test.1 仍是历史 netfix2 运行器的本地打包版本，本轮没有重新编译或公开二进制。
- 上游 PR #1 核对时仍 open、未合并；后续 Python CM 保护不属于该 PR。

据本机用户排查，先前内核崩溃由 Snap 版 Office 引起。此事已从 Felix-Proton 待排查清单移除。

启动加速等待约 10～30 秒已获用户接受；UU 窗口自由缩放暂缓。异机及全面端到端兼容尚未验收。Steam Fossilize 的历史 CPU 占用已经完成归因，按用户要求保留设置。

具体实现、验证边界与回退见 [工作说明](WORK_REPORT.md)、[测试](TESTING.md) 和 [诊断](DIAGNOSTICS.md)。
