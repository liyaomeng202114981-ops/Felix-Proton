# 取消、删素材与关闭窗口

## 验证结果

| 操作 | 环境 | 结果 |
| --- | --- | --- |
| A、B 正在预览时取消第三次选窗 | 独立候选 | Ubuntu 返回取消，本次选择器关闭，A、B 继续取帧 |
| 关闭已共享的 A | 独立候选 | A 的会话、帧连接和占位项被清理，B 继续取帧 |
| 测试窗 B 保持打开，从场景删除它的素材 | 原 Dock 版 | 对应 PipeWire 共享自行结束，帧 socket 随后移除，伴侣主窗口仍在 |

## 清理逻辑

每次窗口请求有独立的授权和帧通道。取消只结束正在选择的会话。关窗后对应流退出并清理占位项。窗口素材已经被伴侣保存后，兼容层按句柄追踪它是否仍存在于场景记录中。确认素材被删除后结束对应授权。清理完成后，测试场景恢复为空。
