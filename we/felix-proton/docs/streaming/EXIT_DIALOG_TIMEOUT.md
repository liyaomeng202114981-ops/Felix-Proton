# 退出确认框 8 秒超时异常

2026-11-19，一轮隔离版详细追踪中，退出确认框在关闭请求后约 79.0 毫秒已被检测为映射。约 125.1 毫秒时读到的原始样本为不透明白底，未采到确认按钮。本轮约 10 秒的观察中，未确认深色面板和红色按钮同时出现。

呈现辅助程序从开始接管起约 8.004 秒触发超时，恢复了窗口的原有不透明度。随后 X11 原始像素和 Mutter 合成区域帧都采到了白底。超时分支为隐藏弹窗设定了时间上限。

该轮单独记录，四轮完整分段计时和 24／12 毫秒对照的数据中均未包含它。是否与详细追踪、客户端渲染状态或其他条件有关仍待确认。日常出现频率暂无数据。保留现有 8 秒回退与 24 毫秒稳定阈值。

若在日常版复现，记录触发时刻、Win32 窗口与 X11 窗口 ID 的对应关系、超时前后的原始面板和按钮样本、超时事件与合成区域帧。先用日常的低开销采样确认是否复现，再单独对照详细追踪。
