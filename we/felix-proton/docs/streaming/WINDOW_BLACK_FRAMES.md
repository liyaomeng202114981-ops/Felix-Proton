# 窗口切到后台的黑屏原因

2026-11-19，在 Ubuntu 的 GNOME Wayland 会话中，抖音直播伴侣能够预览获准共享的窗口。切到其他应用后，预览曾变黑，DMA-BUF 帧交付计数仍在增加。切回测试窗时画面曾短暂恢复。帧交付成功只能说明缓冲可传递，不能判断其中的像素是否有效。

## 分层定位

用持续重绘的自有 GTK 窗口做测试。独立进程从 PipeWire 读取获准共享的 DMA-BUF，通过 Vulkan 对三个预期有颜色的位置采样。测试窗仍在重绘时，三处 RGB 同时为零的样本已经出现。采样发生在进入 Wine、WGC 和伴侣预览之前。

复用同一次窗口授权，在同一张 RTX 4060 上对照。前两组保留相同的 DMA-BUF DRM modifier。

| 路径 | 采样帧数 | 三处 RGB 同时为零 |
| --- | ---: | ---: |
| DMA-BUF 隐式同步 | 179 | 9 |
| DMA-BUF 显式同步 | 171 | 0 |
| PipeWire MemFd 读回 | 171 | 0 |
| DMA-BUF 仅线性 modifier | 本机窗口流未协商到格式 | — |

结果指向生产端写入的同步时序。在这套软硬件组合中，原隐式同步路径不能可靠保证读帧时写入已完成。数据支持这一可复现机制。此前伴侣里每次黑屏的成因没有逐帧取证。
