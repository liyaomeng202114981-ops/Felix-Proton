# 连续选窗与多窗口预览验证

2026-11-19 在 Ubuntu GNOME Wayland 上先测独立候选，再通过原 Dock 入口测日常版。两轮均为本地预览，使用自有 GTK 窗口。

## 独立候选

| 操作 | 结果 |
| --- | --- |
| 第一次点「窗口」 | Ubuntu 同时列出 A、B。选择 A 后，伴侣按实际标题添加 812×475 的动态画面 |
| 保留 A，再点「添加素材 → 窗口」 | Ubuntu 再次出现可选列表。授权 B 后，伴侣添加另一个 892×543 的素材，预览采样出现橙紫交替 |
| 核对两条链路 | 伴侣保存了两个独立标题和不同的窗口句柄。B 取帧时 A 的帧数仍增长。A、B 分别交付 2225 帧和 1372 帧，均为 0 帧错误 |

## 原 Dock 版

通过原图标打开，系统窗口列表同时提供 A、B。授权静止的 B 后，伴侣用真实标题添加素材，收到 892×543 的一帧。伴侣的三次预览采样都保留同一画面。用户确认日常选窗成功。原 Dock 这轮覆盖系统列表和静止单窗首帧，双路同时取帧结果来自独立候选。
