# Shared-network dependencies

Felix-Proton calls SHORiN-KiWATA's **shorin-proton-wrapper** and the upstream **passt/pasta** project. These are separate projects; Felix Li's Python integration does not claim their namespace, networking or runtime-management implementations as original work.

- Wrapper: unmodified script at commit `d8ca9e73bf44d14eadfb29c95e17b57990e0b7f4`, SHA-256 `19a5ed00b0571d48bb41c7e38e6f5a254db96e06b6b6370f2680caab265d997c`. Its pinned upstream package metadata declares MIT; the upstream snapshot and all notices are supplied as `proton-wrapper-d8ca9e73-source.tar.gz`. No Felix license replaces the upstream declaration.
- Pasta: unmodified upstream source commit `6aa4f88bd9846411edff3ed70460475b538addca`. The published historical x86-64 binary SHA-256 is `1dd758b40ab9a6ba4fdd5fc6792c11bb180e87fdeb1b56eab6babe4d4a4b3ddd`, requires glibc 2.38+, and is accompanied by `passt-6aa4f88-source.tar.gz`. Preserve its source headers, contributor notices, `LICENSES/GPL-2.0-or-later.txt`, and `LICENSES/BSD-3-Clause.txt`. The principal networking code is GPL-2.0-or-later.

The pasta source revision is linked by the historical build record. The frozen binary reports `unknown version`, which is the upstream Makefile fallback for a source snapshot without Git metadata; that string alone does not establish its revision. The supplied source can be built with its Makefile using a supported Linux C toolchain (`make`), retaining its stated build options. Source availability is distinct from bit-for-bit reproduction of the historical binary; this release does not claim the latter. The wrapper is itself shell/Python source and is called through its normal CLI. Steam Linux Runtime is obtained separately from Valve by the wrapper, with its own notices and download verification; it is not repackaged here.

The runtime's separate corresponding-source index is `SOURCE_INDEX.json`, with its component notices in `THIRD_PARTY_NOTICES.md`. `NETWORK_SOURCES.json` records these network dependencies' exact source and binary hashes. Official Steam and UU clients, proprietary assets, accounts, installed prefixes and private logs are not redistributed. The setup tool extracts the installed UU icon locally on the user's machine.
